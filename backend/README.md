# Inteligência de Dados e API de Integração
Projeto Desenvolvido por alunos da UNIVESP, na disciplina Projeto Integrador V. Nome do Projeto: Sistema de Gestão Hídrica Inteligente.

Diretório responsável pela camada de persistência e comunicação do projeto.
* Banco de Dados: Armazenamento do histórico de variáveis hídricas para análise futura.

API: Construção da ponte de dados que recebe as informações da simulação e as disponibiliza para a interface web.
